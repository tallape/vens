## Vietnamese-style English Spelling  越南式英文正字法v2.1


| **组别**  | **长/紧音音标** | 双附加符号             | **短/松音音标** | 单个附加符号                |
| ------- | ---------- | ----------------- | ---------- | --------------------- |
| **第一组** | /iː/       | ấ / ế / ứ / ï / ÿ | /ɪ/        | á / é / í / ó / ú / ý |
| **第二组** | /æ/        | ẫ / ễ / ỗ / ữ     | /e/        | ã / ẽ / ĩ / õ / ũ / ỹ |
| **第三组** | /uː/       | ä / ë / ö / ü     | /ʊ/        | ă / ĕ / ĭ / ŏ / ŭ / ў |
| **第四组** | /ɔː/       | ẩ / ể / ổ / ử     | /ɒ/        | ả / ẻ / ỉ / ỏ / ủ / ỷ |
| **第五组** | /ɜː/       | ậ / ệ / ộ / ự     | /ə/        | ạ / ẹ / ị / ọ / ụ / ỵ |
| **第六组** | /ɑː/       | ầ / ề / ồ / ừ     | /ʌ/        | à / è / ì / ò / ù / ỳ |

### 注释:

1. 本正字法. 元音的发音完全通过附加符号表示, 字母不变, 保留英文单词的本身拼写. 这个正字法其实主要是辅助阅读, 如果书写使用, 我觉得用单符号的方式就差不多了.
    
2. 符号全是预组合文字. 首选越南文字母. 但是还是不够用, 差一点点. 所以引入了 ă ĕ ĭ ŏ ŭ, ä ë ö ü ï ÿ. 其中 ï ÿ 表示 /iː/. 这些字母在大部分越南文字体都能显示.
    
3. 单符号表示短音, 双符号 (包括双点) 表示长音. 用越南字母的原因就是因为它有大量双符号的预组合文字, 可以避免用后组合文字.
    
4. 字母音的符号是 ā ī ō ū ȳ. ȳ 发 /ai/. ē 不发字母音, 用来表示 /eɪ/, 在法语词很常见, 而 e 字母音 /iː/ 用 ế.
    
5. /ɒ/ 在美音不存在, 在美国英语, 部分发 /ɑː/, 部分发 /ɔː/, 比例大概是 1267:940.

## VENS Transformer

Convert English text documents to VENS (Vietnamese-Enhanced Notation System) orthography.

### Requirements

- Python 3.8+
- Standard library only (tkinter, zipfile, csv, re, etc.)
- No pip installs needed


### Files

```
vens_transformer/
  vens_transformer.py   # Main GUI application
  g2p_vents.csv         # 125,969 word mappings (word -> VENS-A, VENS-B)
  fonts/                # TTF fonts for EPUB embedding

  README.md
```

### Usage

```bash
python vens_transformer.py
```

1. Select input file (TXT, MD, CSV, EPUB) via Browse or drag-and-drop
2. Choose VENS-A (diacritics only) or VENS-B (diacritics + stress marks)
3. Select embedded font for EPUB output (optional)
4. Click "Convert"
5. Output saved as `*_vens.*` next to the input file
